# Laboratorio de Aprendizaje y Decisión

Hub de simuladores de Santiago León López.

Incluye Talento & Riesgo, Knowledge Challenge, Las reglas del juego (Ultimátum y Empresa en crisis), NEXUS, El Flaco y SATURNO.

Para publicar con GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root).

Conserva las conexiones originales a Firebase y Supabase. Talento & Riesgo es individual y SATURNO utiliza almacenamiento local. Las partidas grupales requieren conexión y las reglas de acceso del backend correspondiente.
